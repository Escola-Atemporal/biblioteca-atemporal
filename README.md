# Biblioteca Atemporal

Protótipo demonstrativo público da Escola Atemporal.

O `index.html` oferece navegação pelas seis trilhas e busca temática, sem incluir documentos internos, links para o acervo restrito ou informações de clientes.

## Publicação

Em Settings > Pages, selecionar Deploy from a branch, branch main e diretório / (root). O GitHub Pages gratuito exige que o repositório esteja público no plano Free.

**Não inserir materiais restritos neste repositório público.**
